# Μάθημα 1 — Το πρώτο σου μοντέλο (steady-state)

Σε αυτό το μάθημα φτιάχνουμε έναν **CSTR αντιδραστήρα** (αντιδραστήρας
συνεχούς λειτουργίας με ανάδευση) και τον λύνουμε.

## Το φυσικό πρόβλημα

Ρεύμα με παροχή `Fin` και συγκέντρωση `CAin` μπαίνει στον αντιδραστήρα.
Μέσα γίνεται αντίδραση 1ης τάξης με ρυθμό `r = k*CA`. Το ισοζύγιο μάζας
στη μόνιμη κατάσταση λέει: *ό,τι μπαίνει = ό,τι βγαίνει + ό,τι αντιδρά*.

## Το μοντέλο

Αντέγραψε τον κώδικα στον editor και πάτησε **Εκτέλεση**:

```gproms
MODEL CSTR
  PARAMETER
    Fin  AS REAL  DEFAULT 1.0    # παροχή, m3/h
    CAin AS REAL  DEFAULT 2.0    # συγκέντρωση εισόδου, kmol/m3
    V    AS REAL  DEFAULT 10.0   # όγκος, m3
    k    AS REAL  DEFAULT 0.5    # σταθερά ρυθμού, 1/h
  VARIABLE
    Fout AS REAL
    CA   AS REAL
    r    AS REAL
  EQUATION
    Fout = Fin ;
    r = k * CA ;
    Fin * CAin - Fout * CA - V * r = 0 ;
END
```

## Τι βλέπεις

- **Μοντέλο**: 3 άγνωστοι, 3 εξισώσεις, βαθμοί ελευθερίας = 0 ✓
- **Αποτελέσματα**: `Fout = 1`, `CA = 0.3333`, `r = 0.1667`
- Η αναλυτική λύση είναι `CA = CAin*Fin/(Fin + k*V) = 1/3` — το fgPROMS
  την βρίσκει με τον αριθμητικό επιλυτή Newton.

## Δοκιμές

1. Άλλαξε `k` σε `1.0` → `CA` γίνεται `2/11 = 0.1818`
2. Διπλασίασε το `V` → η μετατροπή αυξάνεται
3. Δες την καρτέλα **Μηνύματα** — δείχνει DOF, σύνοψη, και ότι
   επιλύθηκε με το αναλυτικό Jacobian (NEWTON)

## Κανόνες της γλώσσας

- `PARAMETER` = σταθερές (με `DEFAULT` τιμή)
- `VARIABLE` = άγνωστοι που βρίσκει ο επιλυτής
- Κάθε `EQUATION` τελειώνει με `;`
- Σχόλια με `#`
