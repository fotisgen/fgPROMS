# Μάθημα 2 — Δυναμική προσομοίωση (πώς εξελίσσεται ο χρόνος)

Σε αυτό το μάθημα προσομοιώνουμε μια **δεξαμενή με ανάδευση**: η στάθμη
`h` και η συγκέντρωση `C` αλλάζουν με τον χρόνο.

## Τα δύο νέα στοιχεία

1. **`$x` = παράγωγος ως προς τον χρόνο** (dx/dt) — ο ρυθμός μεταβολής
2. **`SCHEDULE`** — από πού ως πού προσομοιώνουμε και με τι βήμα

## Το μοντέλο

```gproms
MODEL Tank
  PARAMETER
    Fin AS REAL  DEFAULT 0.5
    Cin AS REAL  DEFAULT 1.0
    A   AS REAL  DEFAULT 2.0
    k   AS REAL  DEFAULT 0.05
  VARIABLE
    h    AS REAL
    C    AS REAL
    Fout AS REAL
  EQUATION
    Fout = 0.4 * SQRT(h) ;
    $h = (Fin - Fout) / A ;
    $C = (Fin * Cin - Fout * C) / (A * h) - k * C ;
  INITIAL
    h = 1.0 ;
    C = 0.5 ;
    Fout = 0.4 ;
  SCHEDULE
    SEQUENCE
      CONTINUE FOR t := 0 TO 20 STEP 0.2
    END
END
```

## Τι βλέπεις

- Καρτέλα **Γραφήματα**: καμπύλες `h`, `C`, `Fout` ως προς τον χρόνο
  (ζουμ και hover δουλεύουν)
- Η στάθμη ανεβαίνει γιατί `Fin > Fout` αρχικά — μέχρι η εκροή
  `0.4*SQRT(h)` να φτάσει την εισροή
- Ο επιλυτής είναι **BDF2 με προσαρμοστικό βήμα** — το `STEP 0.2` είναι
  το μέγιστο βήμα· όπου χρειάζεται, το μικραίνει μόνος του

## Δοκιμές

1. Άλλαξε το `STEP` σε `0.01` → πιο πυκνές καμπύλες
2. Βάλε `Cin = 2.0` → η συγκέντρωση καταλήγει ψηλότερα
3. Στην καρτέλα **Αποτελέσματα** βλέπεις τις τελικές τιμές· με κουμπί
   **Εξαγωγή CSV** κατεβάζεις όλη τη χρονοσειρά

## Πώς διαβάζεται το `$`

`$h = (Fin - Fout)/A` σημαίνει: **ο ρυθμός μεταβολής της στάθμης**
ισούται με (εισροή − εκροή)/επιφάνεια. Χωρίς το `$` θα ήταν εξίσωση
ισορροπίας· με το `$` είναι διαφορική εξίσωση.
