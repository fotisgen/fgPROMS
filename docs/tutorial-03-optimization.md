# Μάθημα 3 — Βελτιστοποίηση σχεδιασμού

Σε αυτό το μάθημα **σχεδιάζουμε** τον CSTR: ποιον όγκο `V` να διαλέξουμε
ώστε να μεγιστοποιήσουμε την παραγωγή `r*V`, με περιορισμό τον όγκο;

## Τι αλλάζει σε σχέση με το Μάθημα 1

- Οι **βαθμοί ελευθερίας** είναι 1 (2 άγνωστοι − 1 εξίσωση) — αυτή τη
  φορά επιτρέπεται, γιατί την ελεύθερη μεταβλητή την επιλέγει ο
  βελτιστοποιητής
- Νέα ενότητα **`OPTIMIZE`** με τον στόχο
- Νέα ενότητα **`BOUNDS`** με τα όρια των μεταβλητών

## Το μοντέλο

```gproms
MODEL CSTROptimize
  PARAMETER
    Fin  AS REAL DEFAULT 1.0
    CAin AS REAL DEFAULT 2.0
    k    AS REAL DEFAULT 0.5
  VARIABLE
    V  AS REAL
    CA AS REAL
  EQUATION
    Fin * CAin - Fin * CA - V * k * CA = 0 ;
  BOUNDS
    V : 0.1 : 20 ;
  OPTIMIZE
    MAXIMIZE V * k * CA ;
END
```

## Τι βλέπεις

- Καρτέλα **Αποτελέσματα**: «Στόχος (Μεγιστοποίηση): 1.81818»
- `V = 20` — ο επιλυτής SLSQP σπρώχνει τον όγκο στο **άνω όριο**
- Αναλυτικά: `CA = CAin*Fin/(Fin + k*V)`, οπότε η παραγωγή αυξάνεται
  πάντα με το `V` → το βέλτιστο είναι στο όριο ✓

## Δοκιμές

1. Άλλαξε σε `MINIMIZE` → βρίσκει `V = 0.1` (κάτω όριο)
2. Άλλαξε τα όρια σε `V : 0.1 : 5` → νέο βέλτιστο `V = 5`
3. Πρόσθεσε δεύτερο όριο: `CA : 0 : 1` → ο επιλυτής το σέβεται

## Γιατί δουλεύει

Οι εξισώσεις γίνονται **περιορισμοί** (constraints), ο στόχος
ελαχιστοποιείται/μεγιστοποιείται από τον αλγόριθμο SLSQP της SciPy,
και η παράγωγος του στόχου υπολογίζεται συμβολικά με SymPy.
