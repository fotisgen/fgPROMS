# Μάθημα 6 — Εκτίμηση παραμέτρων από μετρήσεις

Σε αυτό το μάθημα **προσαρμόζουμε** τη σταθερά `k` ενός batch αντιδραστήρα
σε «πειραματικές» μετρήσεις, όπως κάνει το gEST του gPROMS.

## Τα νέα στοιχεία

1. **`DATA`** — μετρήσεις της μεταβλητής σε χρόνους: `CA : 0 : 1.0, 10 : 0.444 ;`
2. **`ESTIMATE`** — ποιες παραμέτρους προσαρμόζουμε
3. **`BOUNDS`** — όρια για την εκτιμώμενη παράμετρο

## Το μοντέλο

Οι μετρήσεις προέρχονται από την αναλυτική λύση με **πραγματικό k = 0.1**
— ο επιλυτής ξεκινά από εικασία 0.2 και πρέπει να ανακτήσει το 0.1.

```gproms
MODEL BatchEstimate
  PARAMETER
    k   AS REAL DEFAULT 0.2     # αρχική εικασία (αλήθεια: 0.1)
    n   AS REAL DEFAULT 1.5
    CA0 AS REAL DEFAULT 1.0
  VARIABLE
    CA AS REAL
  EQUATION
    $CA = -k * CA^n ;
  INITIAL
    CA = CA0 ;
  SCHEDULE
    SEQUENCE
      CONTINUE FOR t := 0 TO 30 STEP 3
    END
  DATA
    CA : 0 : 1.0, 10 : 0.444444, 20 : 0.25, 30 : 0.16 ;
  ESTIMATE
    k ;
  BOUNDS
    k : 0.01 : 1.0 ;
END
```

## Τι βλέπεις

- Καρτέλα **Αποτελέσματα**: «Εκτιμημένες παράμετροι» → `k = 0.1`
- Πίνακας **Προσαρμογή δεδομένων**: μέτρηση vs μοντέλο — σχεδόν ίσα
- SSE ≈ 0: η προσαρμογή είναι τέλεια

## Δοκιμές

1. Άλλαξε την εικασία σε `0.5` → πάλι βρίσκει 0.1 (τοπικό ελάχιστο;)
2. Βάλε «θορυβώδεις» μετρήσεις (π.χ. 0.43 αντί 0.444) → το k βγαίνει
   κοντά στο 0.1 αλλά όχι ακριβώς — όπως στην πραγματικότητα
3. Εισαγωγή από αρχείο: φτιάξε `data/ca_data.csv` με γραμμές `t,value`
   και γράψε `DATA CA FROM FILE('ca_data.csv') ;`

## Πώς δουλεύει

Κάθε υποψήφια τιμή του k τρέχει μια πλήρη προσομοίωση· ο αλγόριθμος SLSQP
ελαχιστοποιεί το άθροισμα τετραγώνων των αποκλίσεων μοντέλου-μετρήσεων.
