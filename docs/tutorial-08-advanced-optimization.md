# Μάθημα 8 — Προχωρημένη βελτιστοποίηση

Το fgPROMS διαθέτει πλήρη στοίβα βελτιστοποίησης: **HiGHS** για γραμμικά και
ακέραια προβλήματα, **SLSQP** για μη γραμμικά και **Ipopt** ως δίχτυ ασφαλείας,
συν **δυναμική βελτιστοποίηση** (gOPT-lite) όπου ο στόχος υπολογίζεται στο
τέλος μιας προσομοίωσης.

## 8.1 Γραμμικός προγραμματισμός με HiGHS

Όταν ο στόχος και όλοι οι περιορισμοί είναι γραμμικοί, ο επιλυτής HiGHS
αναλαμβάνει αυτόματα. Το κλασικό πρόβλημα: μεγιστοποίηση 3x + 2y με
x + 2y ≤ 4 και 2x + y ≤ 5:

```gproms
MODEL LinearProgram
  VARIABLE
    x AS REAL
    y AS REAL
  EQUATION
    x + 2*y <= 4 ;
    2*x + y <= 5 ;
  BOUNDS
    x : 0 : 10 ;
    y : 0 : 10 ;
  OPTIMIZE
    MAXIMIZE 3*x + 2*y ;
END
```

Η βέλτιστη λύση x = 2, y = 1 με στόχο 8 — επαληθεύεται στα tests με τον
`scipy.optimize.linprog` (1e-9). Πρόσεξε: το fgPROMS επιλέγει τον επιλυτή μόνο
του — αν προσθέσεις έναν μη γραμμικό όρο (π.χ. `x*y`), πέφτει αυτόματα στο
SLSQP/Ipopt.

## 8.2 Ακέραιος προγραμματισμός (MILP)

Μεταβλητές τύπου `INTEGER` + γραμμικό μοντέλο → ο HiGHS λύνει MILP. Φόρτωση
φορτηγού: παρτίδες Α (10 kg, κέρδος 30) και Β (15 kg, κέρδος 40), όριο 45 kg:

```gproms
MODEL TruckLoad
  VARIABLE
    nA AS INTEGER
    nB AS INTEGER
  EQUATION
    10*nA + 15*nB <= 45 ;
  BOUNDS
    nA : 0 : 10 ;
    nB : 0 : 10 ;
  OPTIMIZE
    MAXIMIZE 30*nA + 40*nB ;
END
```

Η βέλτιστη φόρτωση: 3 παρτίδες Α + 1 παρτίδα Β (ακριβώς 45 kg), κέρδος 130 —
η ακέραια λύση δεν «στρογγυλεύει» τη συνεχή (4×Α θα έδινε μόνο 120).

## 8.3 Δυναμική βελτιστοποίηση: η θερμοκρασία ως μεταβλητή ελέγχου

Σε μοντέλο με `SCHEDULE`, μια παράμετρος **χωρίς DEFAULT αλλά με BOUNDS**
γίνεται μεταβλητή ελέγχου — κάθε υποψήφια τιμή τρέχει πλήρη δυναμική
προσομοίωση και ο στόχος αποτιμάται στο τέλος. Παράλληλες αντιδράσεις
A→B (επιθυμητό, E = 60 kJ/mol) και A→C (άχρηστο, E = 80 kJ/mol): χαμηλή
θερμοκρασία ευνοεί την εκλεκτικότητα, αλλά επιβραδύνει — υπάρχει **πεπερασμένο
βέλτιστο** θερμοκρασίας:

```gproms
MODEL ParallelRxns
  PARAMETER
    k0b AS REAL DEFAULT 1.0E10
    k0c AS REAL DEFAULT 1.0E11
    Eb  AS REAL DEFAULT 60000.0
    Ec  AS REAL DEFAULT 80000.0
    R   AS REAL DEFAULT 8.314
    Temp AS REAL
    tf  AS REAL DEFAULT 5.0
  VARIABLE
    CA AS REAL
    CB AS REAL
  EQUATION
    $CA = -(k0b*EXP(-Eb/(R*Temp)) + k0c*EXP(-Ec/(R*Temp))) * CA ;
    $CB = k0b*EXP(-Eb/(R*Temp)) * CA ;
  INITIAL
    CA = 1.0 ;
    CB = 0.0 ;
  BOUNDS
    Temp : 300 : 500 ;
  SCHEDULE
    SEQUENCE
      CONTINUE FOR t := 0 TO tf STEP 0.1
    END
  OPTIMIZE
    MAXIMIZE CB ;
END
```

Ο επιλυτής βρίσκει T ≈ 321 K — τιμή που συμφωνεί με ανεξάρτητη μονοδιάστατη
αναζήτηση πάνω στην **αναλυτική** λύση CB(tf) = kb/(kb+kc)·(1−exp(−(kb+kc)·tf))
με ανοχή 2 K.

## Τι μάθαμε

* Το fgPROMS επιλέγει μόνο του ανάμεσα σε HiGHS (LP/MILP), SLSQP (NLP) και
  Ipopt — με βάση τη δομή του μοντέλου.
* Οι ακέραιες μεταβλητές δίνουν γνήσιες MILP λύσεις.
* Η δυναμική βελτιστοποίηση χρησιμοποιεί παραμέτρους ελέγχου με BOUNDS —
  ο στόχος είναι η τελική κατάσταση της προσομοίωσης.
